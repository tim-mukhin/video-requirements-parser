# Cursor flickers between pointer and default everywhere in VS Code

Source: https://github.com/microsoft/vscode/issues/337449  (reporter: khusantoy, filed 2026-09-23)

Does this issue occur when all extensions are disabled?: Yes/No

- VS Code Version: 1.139.0
- OS Version: MacOS

The mouse cursor keeps flickering between the hand (pointer) and the default
arrow while hovering over clickable elements anywhere in VS Code
(Activity Bar, Explorer, tabs, buttons, etc.), even when the mouse is not moving.
