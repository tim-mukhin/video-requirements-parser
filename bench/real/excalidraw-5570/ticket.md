# context menu scrolling not working consistently on Android

Source: https://github.com/excalidraw/excalidraw/issues/5570  (reporter: zsviczian, filed 2022-08-14)

I received an issue for Obsidian Excalidraw reporting problems with the context menu positioning and scrolling [#742](https://github.com/zsviczian/obsidian-excalidraw-plugin/issues/742). 

I did my own testing as well: 
- ok on Samsung Note 8
- NOT OK on Pixel 4A 
- ok on iPhone 5SE

Interestingly on both the Samsung Note 8 and the Pixel 4A the browser was the same Chrome version: 104.0.5112.69

According to @pikatwinky the issue did not appear on Xiaomi Redmi Note 8 Pro and Motorola E4 plus with Firefox and Mi browser, but it did appear when using a chromium browser.

This is the screen recording of the Pixel 4A. As you can see the context menu is displayed, then repositioned. I can't observe this repositioning on the Note 8.
