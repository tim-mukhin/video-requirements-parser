# TreeHerder button-icons disappear when you hover the button (for e.g. bug/pin buttons next to intermittent failuers)

Source: https://bugzilla.mozilla.org/show_bug.cgi?id=2092716  (reporter: <email>, filed 2026-11-13)

STR:
1. Visit https://treeherder.mozilla.org/
2. Click some red or orange task.
3. Hover a gray button (e.g. a "file-bug" or "pin/thumbtack" button) in the "Failure Summary" area at the bottom.

ACTUAL RESULTS:
The icon disappears while you're hovering the button.

EXPECTED RESULTS:
The icon should remain visible.

Notes:
This happens in Chrome as well as Firefox.
This happens regardless of your preferred color-scheme in browser preferences (dark-mode / light-mode).
You don't need to be signed in to TreeHerder to test this.
