# Quick Settings menu shifts when a new icon appears in panel in RTL

Source: https://gitlab.gnome.org/GNOME/gnome-shell/-/issues/7356  (reporter: Sam Hewitt (@snwh), filed 2024-01-29)

A [user on Discourse reported](https://discourse.gnome.org/t/a-quick-settings-menu-small-bug-that-greatly-affect-accessibility/19204) that the quick settings menu changes position when changing settings--I was able to reproduce it myself but seems to occur when an icon gets added in the panel after the toggle is activated, in my case when a VPN icon appears.
